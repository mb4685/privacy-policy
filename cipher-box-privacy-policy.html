Privacy Policy

Privacy policy effective date: May 9, 2026

This Privacy Policy describes the principles of data processing in the „CipherBox” application available in the Google Play Store.

1. Application Administrator

The application is administered by its creator/developer.

2. Scope of data collected

The application does not require creating an account or providing personal data such as:

  • name and surname,
  • email address,
  • phone number,
  • home address.

The application only saves data related to the use of educational features, such as:

  • number of exams taken,
  • information about errors made during exams,
  • incorrectly selected answers,
  • user progress statistics.

3. Data Storage Method

All data collected by the app is stored locally on the user's Android device.

This data is not transferred to the developer's servers or shared with third parties, except for the services described in the advertising section.

4. Google AdMob Ads

The app uses Google AdMob advertising services provided by Google LLC.

Google AdMob may automatically collect technical data and device identifiers to display ads, measure their effectiveness, and personalize advertising content.

The data collected by Google may include, among others:

  • device advertising identifier,
  • IP address,
  • device and operating system information,
  • ad interaction data.

More information about data processing by Google can be found at:

https://policies.google.com/privacy

5. User Permissions

The user can delete application data at any time by:

  • uninstalling the application,
  • clearing application data in Android system settings.

6. Data Security

The application has been designed to limit access to data only to the user's device.

7. Changes to the Privacy Policy

The Administrator reserves the right to update this Privacy Policy. Any changes will be published on this page.

8. Contact

If you have any questions regarding the Privacy Policy, please contact the application administrator.
